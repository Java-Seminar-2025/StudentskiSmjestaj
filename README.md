# Studentski smještaj
Ova aplikacija služi za oglašavanje, pretraživanje i iznajmljivanje studentskog smještaja. Ovo su mogućnosti koje aplikacija nudi vlasnicima smještaja i studentima:

1) Mogućnosti koje imaju vlasnici:
- registracija stanodavca (osobni podaci, kontakt)
- izrada i objava oglasa (naslov, opis, cijena po sobi, lokacija)
- određivanje broja i spola stanara
- određivanje raspodjele troškova među stanarima ovisno o vrsti sobe u kojoj borave
- uređivanje i brisanje svog oglasa

2) Mogućnosti koje imaju studenti:
- registracija studenta (osobni podaci, podaci o fakultetu)
- pretraživanje smještaja pomoću filtera kao što su: cijena, lokacija, blizina fakulteta, broj soba, broj cimera
- spremanje željenih oglasa u listu favorita
- rezervacija smještaja
- ako je smještaj namijenjen za više studenata, student koji je prvi rezervirao smještaj može staviti oglas za odabrani smještaj kako bi pronašao cimere (status oglasa prelazi u "djelomično popunjen")
